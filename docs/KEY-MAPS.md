# Key bindings

`key_maps.c` recovers the eight default key binding installers (0x43f550, 0x43f630, 0x43f710, 0x43f7f0, 0x43f8d0, 0x43f9b0, 0x43fa90, 0x43fb70). Each stores action codes `first + i` for the twelve key codes 0x27, 0x2e, 0x26, 0x21, 0x3f, 0x2c, 0x2f, 0x3b, 0x3a, 0x3c, 0x3e, 0x40 in the word table at `+8` of the input object (first codes 0xd6, 0x5e, 0xe6, 0x116, 0x146, 0x176, 0x1a6, 0x1d6). `tools/verify_key_maps.py` runs every original 512 times; evidence: `key-maps-verification.json`.
